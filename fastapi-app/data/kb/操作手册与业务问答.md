# 智能地块提取平台 · 操作手册与业务问答（示例领域文档）

## 一、标准流程
1. 在「系统配置」填写大模型、嵌入模型与空间数据库连接，逐项点击连通性测试；
2. 在「知识库」上传地类认定标准、政策文件、数据说明等领域文档；
3. 打开「地图提取」，在地图上框选矩形或手绘多边形作为提取范围；
4. 用自然语言描述需求，例如"提取这片区域里大于 5 亩的耕地和园地"；
5. 查看执行时间线、统计卡片、地类分布与分析结论，导出 GeoJSON 或保存入库。

## 二、两种提取模式怎么选
- 智能提取：走完整 LangGraph 五节点链路，大模型负责理解需求与归纳结论，适合口径不固定、需要文字结论的场合。
- 空间提取（纯计算）：只按 AOI + 地类 + 最小面积做叠加，结果 100% 可复现、速度更快，适合报数与核查。

## 三、常见业务问答
问：为什么建议先上传知识库文档？
答：知识召回节点会把地类认定标准、面积口径注入大模型上下文，结论里的措辞与口径就能与本单位的规范一致。

问：Agent 问答里的数字可信吗？
答：可信。系统提示词明确约束"涉及面积、数量等数字必须来自工具返回结果，不得编造"，所有数字都出自数据库空间计算。

问：提取记录能干什么？
答：每次智能或空间提取都会落库，保留需求原文、AOI、结果 GeoJSON、统计、执行轨迹与大模型结论，可回看、重载结果，或另存为正式地块。

问：框选范围太小没提取到地块怎么办？
答：系统会自动放大或改用规则网格生成候选地块，并在提示里说明结果是"候选"，需要人工核查；也可以放宽地类与最小面积后重试。

问：换了模型供应商要改代码吗？
答：不用。所有模型都走 OpenAI 兼容协议，只在配置页改 Base URL 与模型名即可热生效；结构化输出会依次尝试 json_schema、function_calling、json_mode，最后退回提示词约束。
